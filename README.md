S# Desenvolvedor Back-End - Turma 176A.DBKE.2N26
Repositório com as atividades desenvolvidas no curso do **SENAI de Americana** para qualificação em **Desenvolvimento Back-End**.

## 🎯 Objetivo do curso 🎯
O curso de Qualificação Profissional de Desenvolvedor Back-End tem por objetivo o desenvolvimento de competências que permitem projetar, desenvolver e manter sistemas e aplicativos
na parte do servidor e seguindo boas práticas, procedimentos e normas.

## ✨ Sobre este repositório ✨

Este repositório reúne exercícios e projetos organizados por módulos de estudo, com foco em :

### Desenvolvimento de Banco de dados com a técnica ORM 🎲|

Módulo com foco no desenvolvimento de aplicações que utilizam banco de dados com a técnica ORM realizando as operações CRUD :
- CREATE -> CRIAR
- READ -> LER
- UPDATE -> Atualizar
- DELETE -> Deletar
    - Com elaboração de algumas consultas(querys) SQL mas os projetos em sua maioria foram desenvolvidos com ORM -> Objeto Relacional Mapeado.

### Desenvolvimento de API REST 📚|

Módulo para desenvolvimento de API REST com operações CRUD utilizando protocolo HTTP com suporte ao aplicativo Postman para testes da API, além da elaboração de documentação da API através do SWAGGER. Na última aula foi desenvolvido uma API com operações CRUD incompletas com foco em geração de TOKENS através do JWT( JSON Web Token).
